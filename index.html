Memory map: Amlogic (S805X, S905X, S905D3, A311D)

The whole map

Amlogic (S805X, S905X, S905D3, A311D), 512 MiB of DRAM starting at 0x00000000. Every address is an offset from the SoC's DRAM base. A slot's absolute address is base + offset.

  1. Firmware and headroom 0x00000000–0x03FFFFFF · 64 MiB — Secure firmware lives in the first 64 MiB. No load slot starts below 0x04000000.
  2. scriptaddr 0x04000000–0x040FFFFF · 1 MiB — boot.scr, kept mapped while it loads the fdt and the kernel
  3. pxefile_addr_r 0x04100000–0x041FFFFF · 1 MiB — the PXE / extlinux configuration file
  4. fdtoverlay_addr_r 0x04200000–0x042FFFFF · 1 MiB — one device-tree overlay, until it is applied
  5. fdt_addr_r 0x04300000–0x044FFFFF · 2 MiB — the device tree, grown by resize and overlays
  6. spare 0x04500000–0x045FFFFF · 1 MiB — spare, so the kernel slot starts on a 2 MiB boundary
  7. kernel_addr_r 0x04600000–0x0D5FFFFF · 144 MiB — the kernel booti runs: a raw Image, or a compressed one decompressed back into this slot. 2 MiB-aligned, so an arm64 Image runs in place
  8. ramdisk_addr_r 0x0D600000–0x14EF4FFF · 120.96 MiB — the initramfs, booted where it is loaded. Runs up to what U-Boot holds at the top of DRAM, so it grows with DRAM
  9. U-Boot (relocated) 0x14EF5000–0x1FFFFFFF · 177.04 MiB — Read on a running board: a 32 MiB framebuffer sized for 4K, a 128 MiB heap, about 1 MiB of U-Boot itself, and 16 MiB kept below its stack.
  10. kernel_comp_addr_r 0x08600000–0x0D5FFFFF · 80 MiB — decompress buffer: a compressed kernel (at most kernel_comp_size, 64 MiB) sits at the bottom of the kernel slot, decompresses here and is copied back down

Room for each file

The size of each load slot. The boot files are small next to the kernel and the initramfs, so they get their own scale here rather than a sliver of the map above.

Amlogic open firmware: the reserved block

The first 16 MiB, drawn on its own scale. Each region's line below says how Linux sees it.

  1. ROM mirror 0x00000000–0x000FFFFF · 1 MiB, no-map — on S805X / S905X a read-only mirror of the boot ROM; on S905D3 / A311D held so every family shares one map
  2. Secure monitor (BL31) 0x00100000–0x001FFFFF · 1 MiB, no-map — trusted firmware and its staging
  3. Secure monitor mailboxes 0x00200000–0x002FFFFF · 1 MiB, no-map — shared buffers between Linux and the secure monitor
  4. ramoops 0x00300000–0x003FFFFF · 1 MiB, mapped — pstore: the previous boot's console and crash records survive a reboot
  5. OP-TEE (optional) 0x00400000–0x00FFFFFF · 12 MiB, no-map only when OP-TEE runs — reserved for OP-TEE only when the firmware includes it; otherwise ordinary memory for Linux
